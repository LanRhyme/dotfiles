# MicYou Noctalia Plugin

Noctalia status bar plugin and control panel for MicYou CLI service

## Features

- Quick CLI service control (start, stop, restart, status monitoring)
- Connection mode switching between Wi-Fi, USB (ADB), and Web
- PipeWire virtual microphone detection and auto configuration
- Audio DSP controls including PureVox AI noise suppression, AEC echo cancellation, dereverb, VAD, AGC, and gain adjustment
- ADB device manager for quick phone connectivity inspection
- Live CLI console log streaming with auto scroll
- Quick launchers for Ghostty TUI dashboard and GUI app
- Rich status bar widget with dynamic icons, tooltip metrics, and context menu
- Full English and Chinese localization

## Configuration

- Executable path auto-detection or custom binary path
- Configurable default mode and port
- Left-click behavior for status bar widget (open panel or toggle service)
- Configurable polling interval and startup auto-launch
